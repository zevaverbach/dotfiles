# Mental Models & Frameworks

## Currently Active

### 80/20 (Pareto)
Find the 20% effort that gets 80% of results. Applied constantly to prioritization — which features matter, which learning resources to focus on, where to spend limited time.

### Hell Yes or No
Decision filter: if it's not an enthusiastic yes, it's a no. Protects against spreading too thin.

### Intuitive Builder Mode
Self-described default: build by instinct, ship fast, learn by doing. Works well for execution but can miss structural problems that explicit frameworks would catch.

## Developing / Seeking

I'm an intuitive builder who recognizes the need for more explicit decision-making frameworks. This is an active area of growth — looking to develop more structured approaches to:
- Architecture decisions (when to build vs. buy vs. delegate to agents)
- Investment of time (which bets to prioritize from the portfolio)
- Technical review (how to evaluate agent-generated code with confidence)
- Long-term planning (connecting daily work to 5-year goals)
